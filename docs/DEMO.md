# سيناريو العرض — مَدَد (5 دقائق)

المرجع: `docs/SPEC.md` القسم 16. القصة: مريض لا يجد دواءه، صيدلية تحدّث في ثوانٍ، والمنصة تحوّل البحث الفاشل إلى خريطة نقص تفيد المؤسسات. كل البيانات تجريبية (شارة «بيانات تجريبية» ظاهرة).

## قائمة ما قبل العرض (قبل بنصف ساعة)

- [ ] افتح https://madad-6p2.pages.dev في Chrome، واجعل اللغة العربية.
- [ ] من الزر العائم أسفل بداية الشاشة «تبديل الدور» اختر **«إعادة ضبط بيانات العرض»** وأكّد، ثم تأكد أنك «زائر».
- [ ] افتح الصفحة الرئيسية `/` مرة واحدة مع الاتصال ليُخزَّن الموقع للعمل بلا إنترنت، وافتح صفحة دواء واحدة.
- [ ] جهّز نافذة ثانية أو تبويبًا لمشاهدة المريض إن أردت (لا حاجة، يمكن التبديل).
- [ ] اشحن الجهاز، وأغلق الإشعارات، وكبّر الخط قليلًا للعرض.
- [ ] شغّل نسخة محلية احتياطية: `npm run build && npx vite preview` وتأكد أنها تعمل.
- [ ] سجّل فيديو قصيرًا للسيناريو مسبقًا.
- [ ] تأكد أن Google sign-in ليس ضروريًا: كل العرض يمر عبر مبدّل الأدوار.

### 1. المشكلة (30 ث)

- **الدور:** زائر. **الصفحة:** `/` (P-01).
- **قل:** «مريض سكري في خان يونس يتنقل بين الصيدليات بلا معلومة.»
- **يرى الجمهور:** صفحة البحث البسيطة، حقل البحث، وشارة «بيانات تجريبية».

### 2. البحث (60 ث)

- **الدور:** زائر.
1. في حقل البحث اكتب «انسولين» (بلا همزة) واضغط «بحث». تظهر نتائج الإنسولين.
2. غيّر إلى «إنسولين» (بهمزة) ثم «insulin»: **النتائج نفسها**. هذا يثبت أن البحث لا يتأثر بالهمزات واللغة.
3. اكتب الباركود `6250000000001` واضغط «بحث»: يفتح مباشرة **باراسيتامول 500**.
4. ارجع وافتح إنسولين أسبارت (`/medicine/insulin-aspart?gov=all`) (P-03).
- **يرى الجمهور:** صيدليات بشارات مختلفة، وبجانب كل شارة وقتها: «متوفر» حديثًا، و«يحتاج تحديث»، و«غير مؤكد».
- **قل:** «المنصة لا تكذب: البلاغ القديم لا يظهر مؤكدًا.» أشر لزر «المتوفر فقط» وللوقت بجانب كل شارة.

### 3. عدم التوفر والتنبيه (45 ث)

- **الدور:** مريض (من المبدّل: «تبديل الدور» ← «مريض»).
1. افتح `/medicine/levothyroxine-100?gov=gaza` (أو ابحث «ليفوثيروكسين» واختر غزة).
2. **يرى الجمهور (P-05):** رسالة «لم تُبلغ أي صيدلية في غزة…» مع الأفعال المتاحة (اتصال، واتساب، اتجاهات، استفسار).
3. اضغط **«فعّل التنبيه»** («نبّهني عند التوفر»). يظهر تأكيد أن التنبيه فُعّل.

### 4. الصيدلية (60 ث)

- **الدور:** موظف صيدلية (صيدلية الشفاء، غزة).
1. من المبدّل اختر «موظف صيدلية»، فتفتح `/pharmacy-portal`.
2. افتح التحديث السريع `/pharmacy-portal/update` (PH-02) واكتب في البحث «ليفوثيروكسين 100».
3. في سطر الدواء اضغط **«متوفر»** (من مجموعة متوفر/محدود/غير متوفر)، ثم **«حفظ»**. لا يوجد حقل سعر لموظف الصيدلية.
4. تظهر رسالة «تم تحديث دواء واحد · ظاهر للعامة الآن».
5. **ارجع إلى «مريض»** من المبدّل وافتح `/medicine/levothyroxine-100?gov=gaza`: يظهر الدواء الآن بشارة «متوفر» ووقت **«حُدّث الآن»**.
6. افتح `/me/notifications`: وصل التنبيه «أبلغت صيدلية الشفاء عن توفر ليفوثيروكسين 100…».
- **قل:** «التحديث استغرق أقل من 30 ثانية.»
- **اختياري (تأكيد الكل):** كموظف صيدلية في `/pharmacy-portal/update` اضغط **«تأكيد الكل كما هو»** ثم أكّد في الحوار، وافتح `/pharmacy-portal/history` (السجل): يظهر سطر «تأكيد N أدوية كما هي».

### 5. الأثر (60 ث)

- **الدور:** مراجِع. **الصفحة:** `/admin/unmet-demand` (AD-06).
- **يرى الجمهور:** جدول حراري للطلب غير الملبّى (الأدوية × المحافظات)، وزر تنزيل CSV. لا تُعرض خلية أقل من 5 ولا أي هوية.
- **قل:** «هذه بيانات لا يملكها أحد اليوم، ويمكن أن توجّه شحنات الأدوية والمساعدات.»

### 6. الثقة (30 ث)

- **الدور:** مراجِع أو مدير نظام.
1. `/admin/verification` (AD-02): اعتماد صيدلية بوثائقها.
2. `/admin/data-quality` (AD-05): كشف الصيدليات ذات البيانات القديمة.
3. إن بقي وقت: `/admin/audit` يُظهر التحديث باسم المنفّذ.

### 7. الختام (15 ث)

- **الدور:** أيّ دور.
- **قل:** «التكلفة الحالية 0$. نحتاج شراكة مع جهة صيدلانية للتوثيق، و10 صيدليات تجريبية في منطقة واحدة.»

## ما بعد العرض

- من المبدّل: «إعادة ضبط بيانات العرض» ليعود كل شيء إلى حالته الأولى للعرض التالي.

## خطة بديلة

| العطل | الحل |
| --- | --- |
| لا إنترنت | الموقع يعمل بلا اتصال بعد أول زيارة: يظهر شريط «أنت غير متصل» وآخر بيانات محفوظة في P-01 وP-03. اشرح أن هذا مقصود لظروف غزة. الأفعال التي تحتاج شبكة تكون معطلة بتلميح. |
| الموقع على الإنترنت متوقف | محليًا: `npm run build && npx vite preview` ثم افتح العنوان الذي يطبعه (وضع mock المحلي بنفس البيانات التجريبية). |
| فشل تسجيل الدخول بـ Google | لا تحتاجه: استخدم مبدّل الأدوار العائم (زائر، مريض، مالك صيدلية، موظف صيدلية، مالك مؤسسة، مراجِع، مدير نظام). |
